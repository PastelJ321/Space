# 로켓 추진제 실험

고등학교 **「역학과 에너지」 팀 프로젝트**로 제작한 로켓 추진제 가상실험입니다. 운동량 보존과 로켓 방정식, 역학적 에너지를 이용해 두 가지 질문을 탐구합니다.

- 로켓에 넣는 추진제가 달라지면 로켓은 얼마나 빠르게 날아갈 수 있을까?
- 지구를 탈출하려면 얼마나 많은 추진제가 필요할까?

**[가상실험 실행하기](https://pastelj321.github.io/Space/)** · [저장소](https://github.com/PastelJ321/Space)

## 실험 방법

1. RP-1, CH₄, LH₂ 중 추진제를 선택합니다.
2. 추진제 질량 비율을 조절하고 이상적 Δv와 연소 종료 예상 속도를 확인합니다.
3. **발사**를 눌러 시간에 따른 수직 속도, 고도, 남은 추진제를 관찰합니다.
4. **경계 적용**으로 탈출 조건에 가까운 비율을 실험하거나, 연소 종료 후 **연소 결과 비교**에서 세 추진제를 같은 조건으로 비교합니다.

긴 비행은 재생 속도를 조절해 관찰할 수 있습니다. 연소가 끝난 뒤에도 상승·낙하는 계속되며, 지표면에 도달하면 멈춥니다. 탈출 가능한 경우에는 일시 정지하거나 초기화할 때까지 계속 진행합니다. 비교표와 그래프는 PNG로 저장해 보고서에 사용할 수 있습니다.

## 물리 모델

추진제를 뒤로 방출하면 운동량 보존에 따라 로켓이 가속됩니다. 중력 손실을 제외한 이상적 속도 변화량은 치올콥스키 로켓 방정식으로 계산합니다.

```text
Δv = Isp · g₀ · ln(m₀ / mf)
```

화면의 속도와 고도는 추진제 소모에 따른 질량 감소와 고도별 중력을 반영한 수직 운동의 결과입니다. 탈출 여부는 지표면의 탈출 속도 11.2 km/s 하나를 고정 기준으로 삼지 않고, 연소 종료 시 상승 중이며 단위 질량당 역학적 에너지가 0 이상인지로 판단합니다.

```text
F = ṁ · Isp · g₀
 dv/dt = F/m(t) − μ/(R + h)²
 dh/dt = v

ε = v²/2 − μ/(R + h) ≥ 0
```

| 조건 | 설정 |
| --- | --- |
| 초기 총질량 | 120 t |
| 추진제 질량 비율 | 75–99%, 산화제 포함 |
| 연소 시간 | 180 s, 일정 질량유량 |
| RP-1 / CH₄ / LH₂ 비추력 | 320 / 370 / 450 s |
| 비행 방향 | 지구 지표면에서 수직 발사 |

비추력은 **추진제 비교를 위한 엔진 성능 가정값**이며, 추진제 고유의 물성값이나 특정 실물 엔진의 인증 성능값이 아닙니다. 초기 총질량을 고정하므로 추진제 비율을 높이면 건조 질량은 줄어듭니다. 표시되는 탈출 경계는 이 조건에서 계산한 값이며, 실제 기체의 탱크·구조 설계 가능성까지 의미하지 않습니다.

대기 저항, 지구 자전, 궤도 진입, 다단 분리와 기체 설계는 계산하지 않습니다. 지표면 도달 이후의 충돌도 계산하지 않습니다. 연소 구간은 RK4로 적분하고, 연소 이후에는 케플러 전파를 사용해 장시간 비행에서도 데이터가 계속 쌓이지 않도록 했습니다.

## 화면과 자료

로켓은 관찰하기 쉽도록 확대 표시하고 고도에 따라 시야를 조정합니다. 지구와 로켓 기준점 사이 거리는 계산 고도를 사용합니다. 지구 표면과 구름은 과거의 NASA Blue Marble 합성 영상이며, 현재 기상이나 실제 발사 장면을 나타내지 않습니다. 실제 기체와 연결된 디지털 트윈은 아닙니다.

3D 표시는 Three.js를 사용하며 WebGL 미지원 환경에서는 2D로 전환됩니다. 렌더링은 최대 30fps와 화면별 픽셀 비율 제한을 적용하고, 대기·일시 정지·숨겨진 탭에서는 연속 렌더링하지 않습니다. 이미지 자산은 저장소에 포함되어 있습니다.

- [NASA Glenn — Ideal Rocket Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/)
- [NASA Glenn — Specific Impulse](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/specific-impulse/)
- [NASA — 탈출과 에너지](https://pwg.gsfc.nasa.gov/stargaze/Lkepl2nd.htm)
- [NASA/GSFC Blue Marble · NOAA 배포 자료](https://sos.noaa.gov/catalog/datasets/blue-marble/)
- [영상 출처와 크레딧](public/assets/CREDITS.md)

## 로컬 실행

Node.js **22.12 이상**이 필요합니다.

```sh
npm ci
npm start
```

[http://127.0.0.1:5173](http://127.0.0.1:5173)에서 엽니다. 진입 파일은 `propulsion_lab.html`이며, HTML을 직접 더블클릭하는 대신 개발 서버로 실행합니다.

```sh
npm test          # 물리 모델 검증
npm run build     # dist/에 정적 배포 파일 생성
npm run preview   # 빌드 결과 확인
```

개발 서버가 실행 중이고 Google Chrome이 설치되어 있으면 `npm run test:browser`로 화면 크기별 배치, 연속 비행, 탈출 경계 적용, 일시 정지와 PNG 저장을 검증할 수 있습니다. 스크린샷은 `test-results/`에 생성됩니다.
